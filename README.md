# Event Table — сайт без подпапок

Все файлы сайта лежат в корне архива. Распакуйте их **в одну папку** и откройте `index.html` или запустите локальный сервер, например `python3 -m http.server 4173`.

## Состав

- `index.html` — страница сайта.
- `style.css` — оформление, адаптивная сетка и анимации.
- `app.js` — фильтры каталога, анимации и мобильное меню.
- `catalog-data.js` — 35 товаров, цены и ссылки на карточки VK.
- `hero-desktop.jpg`, `hero-mobile.jpg` — изображения первого экрана.
- `product-*.jpg` и остальные JPG — изображения товаров сайта.
- `vk-original-*.jpg` — исходные фотографии товаров VK для справки.
- `vk-logo.jpg`, `vk-icon.png` — аватар и иконка сообщества.
- `font-inter-*.woff2` — файлы шрифта.
- `build_standalone.py` — необязательная сборка одного автономного HTML с ресурсами внутри: `python3 build_standalone.py`.
- `.nojekyll` — файл для корректной работы GitHub Pages.

Изображения товаров и первого экрана стилизованы по образцам, а не являются документальной съёмкой. Для одного товара исходное фото VK было недоступно, поэтому использована условная иллюстрация.

## Публикация на GitHub Pages

Загрузите **все файлы** из архива в корень репозитория, чтобы `index.html`, CSS, JS, изображения и шрифты находились рядом. В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**. Бесплатный GitHub Pages доступен для публичного репозитория.
